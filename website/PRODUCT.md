# notify-zh — website

## Register

brand — landing/docs de una librería open source; el diseño ES el producto: tiene que
vender "calidad obsesiva en 2.7 KB" de un vistazo.

## Users & Purpose

Developers (JS/TS, cualquier framework) evaluando una librería de toasts: llegan desde
npm, GitHub o un post; deciden en <30 segundos si instalan. La página debe (1) demostrar
el producto en vivo — los toasts SON la demo, (2) dar el copy-paste de instalación al
instante, (3) responder "¿por qué esta y no react-hot-toast?" con la comparativa.

## Brand personality

Nítida, jugosa, técnica. La identidad canónica es `public/og-image.png` (misma imagen que
`.github/social-preview.png`): navy profundo con glows sutiles, headline blanca extra-bold
con ✨, verde para el peso (~2.7 KB), chips índigo, code pill con sintaxis rosa/verde, y
los toasts en colores VIVOS (verde/índigo/naranja) como protagonistas. Los colores de los
toasts son los del producto real — no decoración.

## Anti-references

- El sitio light genérico anterior (secciones grises, azul Tailwind default).
- Neon/cyber/glassmorphism (había clases muertas de eso — no volver).
- Gradient text, glass cards, hero-metric template.

## Accessibility

Contraste AA (≥4.5:1 body), reduced-motion respetado (la librería misma lo respeta —
la web no puede ser menos), foco visible.
